# 📌 Desafio: Criar e Exibir uma Lista de Posts

## 🎯 Objetivo

O objetivo deste desafio é criar um formulário simples para enviar **novos posts** e exibir a lista de posts criados na tela, em vez de apenas no console.

## 🧠 Habilidades trabalhadas

- `fetch` com `POST`
- Manipulação do DOM
- Trabalhar com `JSON.stringify`
- Captura de evento com `addEventListener`

## 📂 Arquivos

- `index.html` — estrutura da página
- `style.css` — visual moderno e simples
- `script.js` — lógica para envio e exibição dos posts
- `README.md` — instruções do desafio

## ✅ Extra

- Após o envio, o formulário é limpo.
- A lista de posts vai sendo atualizada com os posts enviados.
- Cada post exibido possui **título** e **conteúdo**.

## 🚀 Instruções

1. Abra `index.html` em um navegador.
2. Preencha o título e conteúdo do post.
3. Clique em **Enviar**.
4. Veja o post criado ser adicionado à lista de posts na tela.

---

> Este desafio usa a API gratuita `https://jsonplaceholder.typicode.com`, que simula posts e respostas sem salvar de verdade.
## Contexto do exemplo

A página envia um post de demonstração à API JSONPlaceholder e mostra a resposta na lista. A API simula a criação; os dados não ficam persistidos.
